5.2
External authorities

Linking

We aligned entities to Wikidata, VIAF, the Library of Congress and FAST, using owl:sameAs for people and institutions, rdfs:seeAlso for authority records, and skos:exactMatch for concepts.

5.3
Identifiers

URIs

{{rdf:uris}}

These URIs are stable identifiers in a namespace the project controls. The website is published at this address, but the URIs are not dereferenceable: a static host would need one page per resource, and none is generated, so a resource URI returns 404.
