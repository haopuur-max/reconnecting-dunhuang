=== Post-generation independent validation ===
A complete expected RDF dataset (all layers: entity typing/labels, core conceptual assertions, authority reconciliation, statement provenance/reification) is independently rebuilt straight from reconnecting_dunhuang.xml, then compared for EXACT triple-set equality (expected-actual and actual-expected must both be empty — not merely "does each expected triple exist") plus graph isomorphism, against the serialized .ttl, the serialized .rdf, and the in-memory graph produced this run. This full-graph diff catches both a triple whose content is wrong (e.g. a corrupted identifier value) and any unexpected extra triple, neither of which an existence-only check can see. The validator does not call any Converter method, and rebuilds the predicate for each dm:-only relation directly from the XML rather than reusing the DM_PROPERTIES lookup table, which reduces the risk that a shared mapping bug goes undetected. It still shares generic namespace constants, XML/URI helpers, and the SCHEME_LABELS text lookup with the converter, since those encode no project-specific structural mapping decision.
