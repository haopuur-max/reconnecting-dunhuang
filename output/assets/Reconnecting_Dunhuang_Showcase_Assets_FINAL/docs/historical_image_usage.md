# Historical Image Placement Guide

These five images are the recommended real historical-image set for the final Showcase.

## 1. `hero_cave16_manuscripts.jpg`
**Recommended use:** Hero / opening section.
- Full-width or large split-screen crop.
- Dark or parchment gradient overlay for title readability.
- Best visual anchor for the Library Cave / manuscript discovery story.

## 2. `history_pelliot_cave17.jpg`
**Recommended use:** History / dispersal section.
- Medium-large editorial image.
- Pair with the narrative around the manuscript dispersal and early twentieth-century explorers.

## 3. `entity_wang_yuanlu.jpg`
**Recommended use:** Entity Explorer / discovery section.
- Portrait card or side image.
- Do not stretch full-width; preserve documentary character.

## 4. `manuscript_pelliot_chinois_2778.jpg`
**Recommended use:** Manuscript / TEI / source-text section.
- Excellent detail image next to TEI annotation or "From Text to Knowledge".
- Can also serve as a subtle background crop behind source-text excerpts.

## 5. `context_donor_portrait_cave17.jpg`
**Recommended use:** Optional cultural-context divider / side visual.
- Use sparingly.
- Good for a section transition or low-opacity background detail.
- Do not make it the main hero image.

## Visual handling
- Preserve documentary images without decorative AI-style filters.
- Prefer subtle warm grading only through CSS overlays.
- Do not crop away historically meaningful content.
- Keep source / license credits visible in the final credits section.
